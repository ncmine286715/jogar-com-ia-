# Efeitos sonoros (SFX)

A Zoeira já vem com efeitos **gerados na hora** (não precisa de nenhum arquivo).
Se quiser usar os seus próprios sons, coloque arquivos `.wav` aqui com estes
nomes que eles substituem os gerados:

- `boom.wav`    — momentos de tensão/morte (ex: "morri", "game over")
- `airhorn.wav` — zoeira/comemoração (risada, "caralho", "eita")
- `ding.wav`    — acerto/positivo ("boa", "consegui", "matou")
- `rimshot.wav` — piada/deboche ("ba dum tss")

Dica: use `.wav` curtos (menos de 2s). Ajuste o volume em `config.py`
(`SFX_VOLUME`) e o intervalo mínimo entre efeitos (`SFX_COOLDOWN`).
